# Project files

Design material for Tether lives here, outside the Go build.

`TETHER-DESIGN.md` is the design spec for the broker: scope, architecture, the tenant model and the phased plan. It's a copy of the version that lives in the forge repo at `docs/superpowers/specs/2026-10-22-tether-mqtt-broker-design.md`. When you change the design, change it there first and copy it back, so the two don't drift.
