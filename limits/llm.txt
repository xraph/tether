# tether/limits

Import: github.com/xraph/tether/limits

Per-tenant connection slots and message rates, keyed by tenant ID string. No mochi, no forge. Safe for concurrent use.

- `New() *Limiter`.
- `(*Limiter).AcquireConnection(tenantID string, max int) bool`: takes a slot. `max <= 0` is unlimited but still counted. Every true needs one `ReleaseConnection`.
- `(*Limiter).ReleaseConnection(tenantID string)`: gives a slot back. Extra releases are ignored; the count never goes negative.
- `(*Limiter).AllowMessage(tenantID string, l tenant.Limits) bool`: one token from the tenant's `golang.org/x/time/rate` bucket. `MessagesPerSecond <= 0` means no limit (the caller substitutes a broker default first if it has one). `Burst <= 0` becomes `ceil(MessagesPerSecond)`, at least 1. One bucket per tenant. When the rate or burst differs from what the bucket last saw, it is updated in place (`SetLimit`, `SetBurst`): tokens carry over, clamped to the new burst. Callers may alternate different snapshots of a tenant's limits (the broker passes each connection's CONNECT-time snapshot); the allowance stays bounded by the most permissive one and is never refilled by the switch.

The rate is per tenant, shared by all its connections. Buckets are kept for every tenant seen and never evicted.
