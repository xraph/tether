# tether (root package)

Import: github.com/xraph/tether

Tether is a multi-tenant MQTT broker for Go. The root package currently exposes:

- `Version` (const string): the current version, "0.1.0".
- Sentinel errors, all `errors.New("tether: ...")`, matched with `errors.Is`:
  `ErrNotFound`, `ErrConflict`, `ErrInvalidInput`, `ErrTenantDisabled`, `ErrNotAuthorized`.

The `auth` package has its own errors (`auth.ErrBadCredentials`, `ErrNotAuthorized`, `ErrUnavailable`, `ErrRateLimited`), distinct from these, because the broker maps them to CONNACK codes.

Store backends wrap these as `tether/<backend>: <op>: %w`.

The REST layer is in `api/`. The broker is in `broker/`, per-tenant limits in `limits/`, and the keysmith and warden plugins that make live connections react to key and role changes in `events/` (see their llm.txt). Per-tenant usage goes to ledger from `metering/`, which also refuses and disconnects a tenant whose ledger plan does not include it (entitlements), and the audit trail (connections, refusals, ACL denials, takeovers, admin changes) goes to chronicle from `audit/`. All three are off by default and each turns on only with its own `enabled`. The standalone server is `cmd/tether`. The Forge extension in `extension/` wires all of it into a Forge app, with ledger's and chronicle's extensions beside it when those parts are on.
