# tether (root package)

Import: github.com/xraph/tether

Tether is a multi-tenant MQTT broker for Go. The root package currently exposes:

- `Version` (const string): the current version, "0.1.0".
- Sentinel errors, all `errors.New("tether: ...")`, matched with `errors.Is`:
  `ErrNotFound`, `ErrConflict`, `ErrInvalidInput`, `ErrTenantDisabled`, `ErrNotAuthorized`.

The `auth` package has its own errors (`auth.ErrBadCredentials`, `ErrNotAuthorized`, `ErrUnavailable`, `ErrRateLimited`), distinct from these, because the broker maps them to CONNACK codes.

Store backends wrap these as `tether/<backend>: <op>: %w`.

The broker is in `broker/` and per-tenant limits in `limits/` (see their llm.txt). The Forge extension lands in a later task. Design: _project_files/TETHER-DESIGN.md.
